# Egypt House Price Predictor — Streamlit

## 1. Files needed

Put these files in the same folder:

- app.py
- segment_models.pkl
- requirements.txt

The `segment_models.pkl` file is the model file generated by the notebook.

## 2. Install dependencies

Open Command Prompt / PowerShell in this folder and run:

```bash
pip install -r requirements.txt
```

## 3. Run the application

```bash
streamlit run app.py
```

A browser window should open automatically.

If it does not, Streamlit will show a local address such as:

```text
http://localhost:8501
```

Copy that address into your browser.

## 4. Important

The app reproduces the feature engineering and segment-selection logic used in the notebook.

It does NOT ask the user for Price because Price is the target.

It also does NOT use Price_per_SQM because:

Price_per_SQM = Price / Area

and therefore using it as an input would cause target leakage.

## 5. If Streamlit is not recognized

Try:

```bash
python -m streamlit run app.py
```

## 6. Recommended folder structure

```text
house_price_streamlit/
│
├── app.py
├── segment_models.pkl
└── requirements.txt
```
